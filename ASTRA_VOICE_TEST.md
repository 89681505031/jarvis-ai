## ⚠️ Возможные проблемы:

### 1. Fish Audio не активирован
**Симптом:** В логах видно "⚠️ Fish Audio не активирован"

**Решение:**
- Проверьте API ключ в `config.json`
- Убедитесь, что `FISH_AUDIO_OK = True`
- Проверьте подключение к интернету

### 2. Голос не устанавливается
**Симптом:** `custom_voice_id` остаётся `None`

**Решение:**
- Проверьте, что `persona_voices['astra']` не `None`
- Убедитесь, что `fish_tts.set_custom_voice_id()` вызывается

### 3. Ошибка генерации
**Симптом:** "❌ Ошибка Fish Audio"

**Решение:**
- Проверьте API ключ
- Убедитесь, что есть баланс на fish.audio
- Проверьте логи Fish Audio API
