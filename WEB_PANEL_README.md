# J.A.R.V.I.S. PRO - Веб-панель мониторинга

## 🚀 ЗАПУСК ПАНЕЛИ МОНИТОРИНГА

### 1. Установка Flask (если не установлен):
```powershell
pip install flask
```

### 2. Запуск веб-сервера:
```powershell
python web_app.py
```

### 3. Открыть в браузере:
- **Панель мониторинга:** http://localhost:5000
- **Генератор ключей:** http://localhost:5000/generate
- **Активация:** http://localhost:5000/activate

## 📊 ФУНКЦИОНАЛЬНОСТЬ ПАНЕЛИ

### Главная страница (Мониторинг):
- 📥 Всего скачиваний
- 👥 Всего лицензий выдано
- ✅ Активных подписок
- 🟢 Пользователей онлайн сейчас
- ⏳ Пользователей триала
- 🔑 Сгенерировано ключей
- 📋 Таблица всех пользователей со статусами

### Генератор ключей:
- Ввод ID покупателя (email/телефон/Telegram)
- Генерация уникального ключа активации
- Копирование ключа в буфер одним кликом
- Сохранение истории генерации

### Активация:
- Ввод ID пользователя
- Автоматическая генерация ключа
- Активация подписки на 30 дней
- Копирование ключа для отправки клиенту

## 🔗 API ЭНДПОИНТЫ

### Отправка статистики из JARVIS:
```python
import requests

# Трекинг скачивания
requests.post('http://localhost:5000/api/track', json={
    'user_id': 'USER_ID',
    'action': 'download'
})

# Heartbeat (онлайн статус)
requests.post('http://localhost:5000/api/track', json={
    'user_id': 'USER_ID',
    'action': 'heartbeat'
})
```

### Получение статистики:
```python
# JSON со всей статистикой
requests.get('http://localhost:5000/api/stats')

# Список пользователей
requests.get('http://localhost:5000/api/users')
```

### Активация через API:
```python
# Активация пользователя
requests.post('http://localhost:5000/api/activate', json={
    'user_id': 'ivan@gmail.com'
})
```

## 🔐 БЕЗОПАСНОСТЬ

Для продакшена рекомендуется:
1. Добавить авторизацию (логин/пароль)
2. Настроить HTTPS
3. Вынести на выделенный сервер
4. Настроить бэкапы базы данных

## 💡 ПРИМЕР ИСПОЛЬЗОВАНИЯ

1. Клиент скачивает JARVIS PRO → трекинг скачивания
2. JARVIS показывает клиенту его ID
3. Клиент отправляет ID вам (Telegram/WhatsApp)
4. Вы заходите на панель → Генератор ключей
5. Вводите ID клиента → Генерируете ключ
6. Отправляете ключ клиенту
7. Клиент активирует → Подписка на 30 дней
8. Следите за статистикой на панели!
