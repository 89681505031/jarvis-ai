# План: Умные фичи для JARVIS

## Обзор
Добавить 4 новые функции в `jarvis_fixed.py`:
1. Контекстная память — связь между разговорами
2. Планировщик задач — todo-лист с приоритетами и дедлайнами
3. Анализ экрана — анализ открытых окон/приложений
4. Паттерны поведения — изучение привычек пользователя

---

## 1. Контекстная память

### Что делает
Пользователь может сказать: "напомни, что ты мне советовал вчера" или "что я тебе рассказывал про проект". JARVIS ищет в истории сообщений ключевые темы и возвращает релевантную информацию.

### Изменения в memory.json
Добавить новые поля:
```json
{
  "topics": ["проект", "код", "работа"],
  "topic_history": [
    {"date": "2026-09-12", "topics": ["проект", "код"], "summary": "Обсуждали проект JARVIS"},
    {"date": "2026-09-11", "topics": ["работа"], "summary": "Говорили о работе"}
  ],
  "advice_log": [
    {"date": "2026-09-12", "advice": "Используй Three.js для 3D Orb"},
    {"date": "2026-09-11", "advice": "Обнови зависимости"}
  ]
}
```

### Реализация
**Файл:** `jarvis_fixed.py`

**Новые методы:**
- `_extract_topics(text)` — извлечение ключевых слов из сообщения (50 строк)
- `_save_topic_topics(text, response)` — сохранение тем и советов в memory.json (30 строк)
- `search_context(query)` — поиск по истории тем (60 строк)
- `context_memory_cmd(query)` — обработчик команды "напомни/что ты говорил про..." (40 строк)

**Интеграция:**
- Вызывать `_save_topic_topics()` после каждого ответа GigaChat (в `ask_gigachat()`)
- Добавить команду в `process_command()`

## 2. Планировщик задач (Todo List)

### Что делает
Пользователь может сказать: "добавь задачу купить молоко на завтра с приоритетом высокий" или "покажи мои задачи".

### Изменения в memory.json
Добавить поле:
```json
{
  "tasks": [
    {
      "id": 1,
      "text": "Купить молоко",
      "due": "2026-09-13T10:00:00",
      "priority": "high",
      "done": false,
      "created": "2026-09-12T15:00:00"
    }
  ]
}
```

### Реализация
**Файл:** `jarvis_fixed.py`

**Новые методы:**
- `_add_task(text, due=None, priority="medium")` — добавить задачу (40 строк)
- `_list_tasks(filter="all")` — показать задачи (фильтр: all/active/done/high) (50 строк)
- `_complete_task(task_id)` — отметить задачу выполненной (30 строк)
- `_delete_task(task_id)` — удалить задачу (20 строк)
- `_check_overdue_tasks()` — проверка просроченных задач (30 строк)
- `task_cmd(action, text="", task_id=None)` — обработчик команд (50 строк)

**Команды:**
- "добавь задачу [текст] на [дата] с приоритетом [низкий/средний/высокий]"
- "покажи задачи [все/активные/высокий приоритет]"
- "выполнить задачу [номер]"
- "удалить задачу [номер]"
- "какие у меня задачи на сегодня/завтра/неделю"

**Дополнительно:**
- Автоматическая проверка просроченных задач при запуске
- Напоминание о задачах с высоким приоритетом

## 3. Анализ экрана

### Что делает
Пользователь может сказать: "проанализируй экран" или "что открыто на компьютере". JARVIS делает скриншот, определяет открытые окна и приложения, анализирует через GigaChat.

### Реализация
**Файл:** `jarvis_fixed.py`

**Новые методы:**
- `_get_open_windows()` — получение списка открытых окон через win32gui (60 строк)
- `analyze_screen()` — сделать скриншот + анализ открытых окон (50 строк)
- `screen_analysis_cmd()` — обработчик команды "проанализируй экран" (30 строк)

**Использование существующего:**
- `take_screenshot()` — уже есть, использовать для скриншота
- `ask_gigachat()` — для анализа содержимого скриншота

**Данные:**
- Список открытых окон с иконками
- Активные приложения
- Время работы системы
- Загрузка ресурсов во время скриншота

## 4. Паттерны поведения

### Что делает
JARVIS изучает привычки пользователя:
- Во сколько чаще всего даёт команды
- Какие команды выполняет чаще всего
- В какие дни активнее всего
- Какие темы обсуждает чаще

### Изменения в memory.json
Добавить поле:
```json
{
  "behavior_patterns": {
    "command_hours": {"09": 5, "10": 12, "14": 8, ...},
    "top_commands": {"погода": 45, "время": 30, "новости": 20},
    "top_topics": ["работа", "код", "музыка"],
    "activity_by_day": {"Monday": 15, "Tuesday": 22, ...},
    "first_command_today": "2026-09-12T08:30:00",
    "total_commands": 1250,
    "sessions_count": 89
  }
}
```

### Реализация
**Файл:** `jarvis_fixed.py`

**Новые методы:**
- `_track_command(cmd)` — запись команды в статистику (40 строк)
- `_track_topic(topic)` — запись темы в статистику (20 строк)
- `_get_behavior_insights()` — анализ паттернов (50 строк)
- `behavior_cmd(action)` — обработчик "какие у меня паттерны/статистика" (40 строк)

**Интеграция:**
- Вызывать `_track_command()` в `process_command()` после выполнения
- Вызывать `_track_topic()` после извлечения тем из разговора
- Обновлять `first_command_today` каждый день

**Команды:**
- "какие у меня паттерны" — показать статистику
- "покажи статистику команд" — топ команд
- "когда я активнее всего" — пиковые часы
- "сколько раз я тебя использовал" — общая статистика
